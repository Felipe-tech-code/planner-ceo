# Planner CEO

Landing page responsiva em HTML, CSS e JavaScript. Visual branco, cinza e bordô #550000.

## Visualizar
Abra index.html no navegador. Estilos, scripts e imagem estão incorporados ao HTML; nenhuma instalação é necessária.

## Editar
Edite index.html diretamente. Procure const CHECKOUTS no final do arquivo para preencher os seis links HTTPS de compra. As chaves são digital, fisico, planilha, planners, completo e master. Sem link válido, o botão informa que a compra está indisponível.

O PNG separado é uma cópia do retrato utilizado, com fundo removido por IA. As prévias dos produtos são ilustrativas e os dados financeiros são fictícios. Confirme os links e as informações reais de entrega e do encontro ao vivo antes de publicar.

## Hospedagem
Este é um site estático. index.html é a página inicial para hospedagem, incluindo GitHub Pages. Nenhum repositório remoto ou publicação foi configurado.

Consulte LEIA-ME.txt para as demais instruções de edição. Nesse documento, onde constar planner-ceo.html, use index.html nesta pasta.
